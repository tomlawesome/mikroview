RouterOS · Firewall live view

See what your
firewall just did.

MikroView turns RouterOS's firewall log into a live picture of your network: every boundary the router watches, every connection accepted, dropped or rejected, and which rule decided it. The router pushes; MikroView never logs in to it — no RouterOS credentials, no API access. Start it with docker compose up, paste the setup commands it generates into the router once, and the picture builds itself.

What you get

The fall

The landing view. One column per boundary your rules mention — guest to internet, LAN to servers — with time pouring down it. A boundary whose rules don't log is drawn as a solid dark stripe, so "switched off" never looks like "quiet".

Topography

A map of the place: internet above, the router at the waist, your networks below, drawn from the rule, NAT and address tables the router pushes. It shows where logging is dark, and Tune logging hands back an export with those rules switched on.

The stream

Row by row, as it happens: accepted, dropped or rejected, and the rule that made the call, decoded from a short log-prefix convention. Filter by device, IP or CIDR, port, protocol, interface or rule — all client-side, all instant.

Flags and a watchlist

Port scans, activity spikes, repeated hits on critical ports (SSH, RDP, Winbox…) and more raise a flag for a human to review — never an automatic action. The watchlist covers the other direction: what should happen, and what deviated.

Push, not poll

RouterOS forwards firewall log lines over syslog-over-TLS, and can push its config and encrypted backups the same way. MikroView never connects to the router and holds no RouterOS credentials; the only secret on the router is an ingest token MikroView minted for that device. No polling loop hammering the router — just a stream it was already able to send. One Go binary, UI embedded, distroless image.

Secure by default, on disk by choice

Sign-in is always required, HTTPS is on out of the box, local accounts or OIDC/SSO. Events live in memory unless you opt in to encrypted per-day history files; an optional SFTP drop box keeps your router's own nightly backups for the day the router is gone.

Two more ways to look

Quickstart

$ docker run -d --name mikroview \
    -p 6514:6514/tcp -p 443:8080 \
    ghcr.io/tomlawesome/mikroview:latest

Then point RouterOS at it — syslog over TLS (RouterOS 7.18+), and the built-in guided wizard writes every command with your values already filled in. latest is the most recent release; each release is also tagged v<version> if you'd rather pin one. Reference: docs/routeros-setup.md and docs/reading-the-fall.md.
