# Pre-release review: v0.5.0

Reviewed: `55a84437` (dev after the M13 merge; first pass), `ba4a6c97`
(the `fix/0.5.0-release-gate` batch carrying the first-pass fixes; topic
pass) and `d7b820b4` (the same batch with every topic fix in; security
audit). Fix commits are named per finding below. The next release reviews
what changed after `d7b820b4`, plus the security fixes named in the audit
section once they are listed.

**Disclosure rule.** Security findings appear here only once fixed
robustly -- a failing-then-passing test, merged to `main`, re-confirmed by
an independent refuter on the final code -- and are listed with the commit
that fixed them. Anything unfixed lives in a confidential GitLab issue and
is not named here. This file is never deleted: the next release reviews
only what changed since the commit named above, plus new code.

## Method

Every pass used the same shape: one finder agent per area or topic x slice,
reporting what it read ("coverage") and what it found; every medium or high
finding then went to an independent refuter agent briefed to disprove it.
Only findings the refuter confirmed are listed as confirmed. Lows were not
refuted. Finders: Claude Sonnet 5; refuters: Claude Sonnet 5; triage,
grouping and design rulings: Claude Fable 5.
