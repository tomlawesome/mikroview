# Pre-release review: v0.7.1

Reviewed: everything that changed between v0.7.0 (`c928dc2a`) and this
release. v0.7.1 is a patch release: it changes how the image is copied
to GitHub's registry (#1563) and fixes a test that broke on v0.7.0's own
upgrade recording (#1566).

**Disclosure rule.** As for v0.7.0: security findings appear here only
once fixed and named with their fix commit; anything open lives in a
confidential issue. This file is never deleted.

## Method

Every change was reviewed inline by an agent that did not write it, with
a test written first by a different agent from the fixer. Security ran
last and alone, on the release range, under the backend, data,
frontend and supply-chain lenses. Review issue #1568.

## Results

Nothing High. The inline review of #1563 found two Mediums -- the
floating tag could move before the image was signed, and a stale
document -- and they were fixed before merge (`e8278cc3`), along with a
Low and a Note. Security found one Medium.

Security stage: one Medium, fixed before release. The token that writes
images to GitHub's registry was readable by every job in a release
pipeline; it now lives on the signing runner's host beside the signing
key, read only by the publishing job (#1569, fix `80c805c2`).

The fix's own review found three Lows: a stale comment (fixed), a long
comment line (style, left), and a token file saved by hand with Windows
line endings failing to log in (left: the documented setup step writes
the file cleanly).

## v0.7.0's deferred findings

v0.7.0's review deferred naming its open security findings (#1547, to be
fixed in v0.8.0). v0.7.1 fixes none of them, so they stay undisclosed
until the release that fixes them (owner decision, #1570).
