## Direction AD — the survey, in step

Both notes resolve in one move: **the map becomes a column of the
ledger itself.**

- **Aligned by construction, not by care**: every row draws its own
  mark in its own plot cell, vertically centred on the row — map and
  record cannot fall out of step under any sort, filter or scroll,
  and there is no sync code to get wrong.
- **The geography moves to the horizontal**: hosts plot the octet
  across the plot column (the outside a hatched, declared sliver at
  its edge; the unclaimed range the long empty middle), ports plot
  the banded ruler, rules plot the tally bar — one axis per tab,
  always in the row. A cluster in address space reads as a vertical
  run of pins down one x-column.
- **The seam is the width handle**: the plot/record boundary drags
  like the pane splitter it is — wide (octet sublabels surface) to a
  sliver of pins — **a per-user preference, persisted and applied
  before first paint, never moved by the app**: the same grammar as
  the rail's density and metrics' view choice. `[` / `]` nudge it
  from the keyboard.
- **AA's laws carry verbatim**: honest geography, the stake grammar
  (solid named / dashed unnamed; the amber tick lives in the
  record), the unnamed-first fold, filter + lens acting on rows with
  marks simply following, the pocket survey's mobile drawer
  (unchanged from round 3; on a phone the seam is moot), and #490's
  read-only grammar.
- Accessibility: mark and record are one row, so screen readers get
  position as words ("at .77, on LAN ground"), spoken once per row;
  arrows walk rows with nothing to keep in sync.
- Build note: the seam is one CSS variable; marks are
  absolutely-positioned children of their row's plot cell — no
  measurement, no scroll-sync, no drift. Below sliver width the plot
  column drops out, leaving exactly W's roll.
