The handle

»6

26 × 44px, glass, top-left, fixed. First in tab order after the skip-link; Enter opens the drawer. Wears the open-flag count — the one number that must survive docking. No other duty: connection loss stays the banner's job.

Keyboard, end to end: Tab reaches handle/rail items in order · Enter activates · drawer: focus lands on the current page, Esc returns it to the handle · docking returns focus to the handle · pinning keeps focus where it sits. Every control is a real button with a spoken label; the states are announced ("navigation docked", "navigation pinned open").
Persistence: one preference, three values (full · icons · docked), stored per user, applied before first paint so the rail never flashes between states on load.
