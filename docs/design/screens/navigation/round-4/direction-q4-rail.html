Docked — 0px + the handle. The fall owns the screen. The handle — the network fanning out of the edge — is the only chrome, vertically centred on the viewport, always. It wears the alarm badge: docking navigation never docks the alarm.
Three persistent states, one owner. The state is a per-user preference and survives reload. Round 1's auto-collapse on Live places is superseded — with dock available, immersion is a choice, not a guess, and the rail never moves on its own.
Defaults: full at ≥1280px, icons below. Docked is never a default — an operator docks it themselves, so they know where the handle lives.
Broken is a ring, not a number. The count badge belongs to Flags alone. Anything else in a broken state — Watchlist here, while the egress-cadence watch is broken — wears a red ring on its icon, in every density. The ring clears when the break clears; the aria-label says why it is there.

Connection state: the rail-head dot exists in full and icons. Docked, connection loss is the banner's job (it renders regardless of rail state) — the handle stays a one-job control: bring the rail back, and say if the alarm has something for you.

The handle

6

The mark is the map in miniature: a hub on the edge, links fanning inward — the network waiting to come back out. The hub breathes (the same pulse the receiving dot uses; still under reduced motion). 30 × 84px, vertically centred on the viewport, always — independent of scroll and page. First in tab order after the skip-link; Enter restores. Wears the open-flag count; connection loss stays the banner's job.

Keyboard, end to end: Tab reaches handle/rail items in order · Enter activates · restore lands focus on the current page item · docking returns focus to the handle. Every control is a real button with a spoken label; state changes are announced ("navigation docked", "navigation restored — icons only").
Persistence: one preference, three values (full · icons · docked), stored per user, applied before first paint so the rail never flashes between states on load. The handle never writes the preference — it only re-applies the undocked half of it.
