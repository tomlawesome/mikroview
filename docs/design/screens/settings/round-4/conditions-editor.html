A condition is a sentence, one per line: field · verb · value. The verbs are worded per field (is · is not · is one of · is not one of · is within · is between · is classed as), and the value control follows the verb — one box for is, chips for one of, a CIDR box for within, two boxes for between. Every line must hold; the gutter says "and" so nobody wonders about "or" (the engine has none).
Counting is one sentence too, built from the engine's real axes (per source · per source and port · per target · per destination port · everywhere; each event or distinct values of a field), with the threshold and window — the numbers Try already knows how to replay — inline where they are read.
Reads as is the honesty line: the whole definition read back as prose, from the exact spec that will be saved, so an operator checks a sentence rather than a form. It updates as the form changes and is what a viewer sees in place of the editor.
