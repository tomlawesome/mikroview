# 1 · Spamhaus DROP — the fetch-and-parse script (guarded: adds once, then sets)
:if ([:len [/system script find name=mv-bl-spamhaus]] = 0) do={ /system script add name=mv-bl-spamhaus policy=read,write,test source="…" } else={ /system script set [find name=mv-bl-spamhaus] policy=read,write,test source="…" }
   the source, 19 lines: fetch https://www.spamhaus.org/drop/drop.txt · read in 32 KB chunks · cut each line at "; SBL…" · refuse wider than /8 · build mv-bl-spamhaus-next, swap it in only if the fetch succeeded
# 2 · Spamhaus DROP — the schedule: daily, 04:17
