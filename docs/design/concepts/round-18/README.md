**`the-docket-opened.html`** — two scenes:

- **The docket**: rows open as drawers — the story in plain English,
  the episode's shape (a small strip of the actual event times), the
  matched log lines, and the actions (open in stream, watch this
  pathway, clear with a note; mend/pause on the broken watch). Flag
  types wear their own colour as a left stripe + mark ink: unplanned
  `#ff5470`, port scan `#ff9e64`, outbound `#f072c8`, repeated drops
  `#e0765a`, surge `#e8b05a` (amber ▲), new talker `#b8c56a`. Tables
  fill the width. Tab counts are bare ink now — no pills; a broken
  watch is a small red ○ beside the watchlist count. Every column
  head sorts (click, ▲/▼) and filters (a quiet dashed row beneath the
  heads) — across all three tabs; drawers travel with their rows.
- **The reach** (`#reach`): where a where-link lands — the topography
  descended to the zone, the card holding the centre, clients nestled
  around it, cam-porch flagged, aggregates in the ratified C bands
  beneath. A client link lands the same view with that client held.
